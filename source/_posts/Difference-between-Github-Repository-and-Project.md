# Difference between Github Repository and Project

Just curious about what "projects" means in Github...

<!-- more -->

## Official Document

### Repository

A repository is the most basic element of Github.

Repositories can be seen as a project's folder.

A repository contains all of the project files (including documentation) and stores each file's revision history.

Repositories can have multiple collaborators and can be either public or private.

### Project

Project boards on Github help you organize and prioritize your work.

You can create project boards for specific feature work, comprehensive roadmaps, or even release checklists.

With project boards, you have the flexibility to create customized workflows that suit your needs.

## Conclusion

In conclusion, "projects" is the abbreviation for "project boards". Simply put, it can be understood as bookmarks such as work schedules, creating work plans, bugs, and processes.
